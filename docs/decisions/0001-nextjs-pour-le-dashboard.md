# 0001. Next.js pour le dashboard

Date : 11 nov. 2026 · Statut : Acceptée

## Contexte

Le cahier des charges prévoit Flutter Web pour les dashboards (question 12, « à valider »).
Le dashboard a été commencé avec Next.js.

## Décision

Le dashboard web est développé avec **Next.js** (App Router), React et Tailwind.
Le maître de stage a confirmé ce choix le 11 nov. 2026.

## Pourquoi

Choix confirmé par le maître de stage. Les autres raisons sont à compléter par la développeuse avec ce qui a été dit.

## Conséquences

- La question 12 du cahier des charges est tranchée pour le dashboard web.
- L'application mobile reste en Flutter (hors de ce dépôt de dashboard).
