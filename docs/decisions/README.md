# Décisions

Une courte note par décision importante, pour se rappeler **pourquoi** on a choisi ainsi.
On n'écrit pas une note pour chaque détail : seulement ce qui serait coûteux à changer ou à oublier.

## Règles

- Un fichier par décision : `NNNN-sujet-en-quelques-mots.md` (0001, 0002...).
- On ne réécrit pas une ancienne décision : si on change d'avis, on écrit une nouvelle note et on marque l'ancienne « Remplacée par NNNN ».
- Une note tient sur une page.

## Modèle

```markdown
# NNNN. Titre de la décision

Date : jj mois aaaa · Statut : Acceptée

## Contexte
Quel problème, quelles contraintes ?

## Décision
Ce qu'on fait.

## Pourquoi
Les raisons, et les autres options écartées.

## Conséquences
Ce que ça change, ce qui reste à faire.
```
